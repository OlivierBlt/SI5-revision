00La démarche ML

À partir de (X, y), trouver f telle que f(X) = y' minimise une métrique M(y, y'). On choisit la métrique avant le modèle. Régression : y continu. Classification : y discret.

Pipeline en validation croisée

  1. Fixer les hyper-paramètres à tester.
  2. Séparer train / test (stratifié en classification).
  3. Pour chaque jeu d'hyper-paramètres, pour chaque fold, sur le fold uniquement : outliers (suppression / cap), manquants (suppression / imputation), représentation (normalisation ; OneHot pour les catégories ; cos/sin pour mois, jour, vent ; TF-IDF / embedding pour les mots), apprentissage, évaluation.
  4. Moyenne ± écart-type sur les folds → choix des hyper-paramètres.
  5. Évaluation une seule fois sur le test.
pipe = Pipeline([("sc", StandardScaler()), ("clf", LogisticRegression())])
gs = GridSearchCV(pipe, {"clf__C": [0.01, 0.1, 1, 10]},
                  cv=StratifiedKFold(5), scoring="f1_macro").fit(X_tr, y_tr)
gs.best_params_, gs.best_score_, gs.score(X_te, y_te)
Fuite d'information : tout ce qui « apprend » sur les données (scaler, imputeur, SMOTE, vocabulaire TF-IDF) doit être dans le Pipeline, pas appliqué avant le split.

CM1Régression linéaire

Trouver la droite (l'hyperplan) qui minimise la somme des erreurs au carré. Avec intercept, la somme des résidus vaut 0. L'erreur est sur y (écart vertical) : exemple U = RI.

Solution 1 : β̂ = (XᵀX)⁻¹ Xᵀ y
Solution 2 : descente de gradient sur J(β) = 1/(2m) Σ (f(xᵢ) − yᵢ)², jusqu'à ∇J = 0

Équation normale : exacte mais coûteuse (~p³) et impossible si colinéarité parfaite. Gradient : passe à l'échelle, marche sans solution fermée (Lasso, log-loss).

Régularisation

J(β) = α‖β‖ + MSE · Lasso L1 = ‖β‖₁ · Ridge L2 = ‖β‖₂² · Elastic = ρL1 + (1 − ρ)L2
  • Lasso : coefficients exactement à 0 → sélection de variables. Ridge : rétrécit, stabilise la colinéarité.
  • α ↑ = plus de régularisation = moins de variance, plus de biais. Normaliser avant.

Points problématiques

  • Outlier : au milieu des autres en x, grande erreur. Point isolé : loin en x, fort levier. Les deux tirent la pente.
  • Range prediction : n'utiliser le modèle que sur la plage d'apprentissage.
  • Colinéarité / normalisation : inutiles pour prédire avec une régression simple ; utiles pour interpréter les poids et pour la convergence de Ridge / Lasso.

Évaluer

R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)² → part de variance expliquée (peut être < 0 en test)
MAE (robuste, unité de y) · RMSE (pénalise les grosses erreurs, unité de y)

LinearRegression().score() = R². Sur le train, il est optimiste.

La relation est-elle linéaire ?

εᵢ = eᵢ / (RMSE₍₋ᵢ₎ · √(1 − hᵢ)) avec hᵢ = 1/n + (xᵢ − x̄)² / Σ(xⱼ − x̄)²

RMSE₍₋ᵢ₎ : modèle appris sans la donnée i. Tous les |εᵢ| < 3 → relation linéaire acceptable. Levier hᵢ proche de 1 → point isolé qui décide de la pente.

Quartet d'Anscombe

Quatre jeux, même β₀ = 3, β₁ = 0,5, MSE ≈ 1,25, R² ≈ 0,67 :

ALinéaire bruité → OK.
BParabole → polynôme degré 2. Résidus structurés (tous |ε| < 3 pourtant).
CDroite + 1 outlier (13 ; 12,74), ε ≫ 3 → le retirer / capper.
Dx = 8 partout sauf un point (h = 1) → aucun modèle fiable.

Message : les statistiques ne suffisent pas, il faut tracer et analyser les résidus.

Régression polynomiale

On crée x₁², x₁x₂, … (PolynomialFeatures) puis une régression linéaire : linéaire en β. Nombre de termes pour d features et degré n : C(d + n, n) (2 features : 3, 6, 10 termes pour les degrés 1, 2, 3). Degré élevé → over-fitting → Ridge / Lasso.

CM2Régression logistique, métriques, déséquilibre

Une droite + MSE ne marche pas en classification : prédictions hors de [0, 1], et un point lointain bien classé déplace la frontière. On veut une courbe en S et une autre perte.

f(x) = σ(β₀ + β₁x) = 1 / (1 + e^−(β₀+β₁x)) = P(y = 1 | x)
classe 1 ⇔ β₀ + β₁x ≥ 0 (frontière linéaire ; le signe suffit si on ne veut pas la proba)
log-loss : J(β) = −Σ [yᵢ log ŷᵢ + (1 − yᵢ) log(1 − ŷᵢ)]
  • Régularisation L1 / L2 / Elastic-Net, coefficient C = 1/λ : C petit = forte régularisation.
  • sklearn : predict (classe), predict_proba (n × K), score = accuracy. Depuis sklearn 1.8, penalty est déprécié au profit de l1_ratio (0 = L2, 1 = L1).
  • Tangente hyperbolique : autre courbe en S, bornée dans ]−1, 1[.

Même accuracy, modèles opposés : l'accuracy ne sert à rien en déséquilibré.

Rééquilibrer (sur le train uniquement)

  • Oversampling (dupliquer la minorité, risque d'over-fitting), undersampling (retirer de la majorité, perte d'info).
  • SMOTE (Chawla 2002) : nouveau = s₁ + λ(s₂ − s₁), λ ∈ [0, 1], s₂ voisin minoritaire de s₁. Borderline-SMOTE (Han 2005) : près de la frontière. ADASYN (He 2008) : là où la majorité domine. Bibliothèque imblearn.
  • class_weight : dict {classe: poids} ou "balanced" = n_samples / (n_classes × bincount(y)). Défaut None.
Coquille du CM : « s1 + random(0,1)*s2 » ; la bonne formule utilise la différence s₂ − s₁ pour rester sur le segment.

Multi-classe

OvR : K classifieurs, max de probabilité. OvO : K(K − 1)/2 classifieurs, vote majoritaire.

CM3Arbres et ensembles

  • Prédiction : descendre jusqu'à une feuille. predict = classe majoritaire, predict_proba = proportions dans la feuille.
  • Frontière en rectangles parallèles aux axes. Solution non unique. Pas besoin de normaliser.
  • Tendance à l'over-fitting ; sensible au déséquilibre → class_weight.
  • Hyper-paramètres : max_depth, min_samples_split, min_samples_leaf (trop petit → over-fit, trop grand → n'apprend rien). tree.plot_tree(clf) pour afficher.
Gini(t) = 1 − Σⱼ P(j | t)² · 0 si pur · max = 1 − 1/c (0,5 en binaire)
Gini du split = Σᵢ (nᵢ / n) · Gini(tᵢ) → on prend le split qui le fait le plus baisser

Exemple du cours (10 dossiers, 3 fraudes) : racine 0,42 ; Statut marital (Marié / autres) 0,30 ; Remboursement 0,343 → on coupe sur le statut marital.

Ensemble learning

P(erreur du vote) = Σ_{k > N/2} C(N, k) εᵏ (1 − ε)^(N−k) · N = 5, ε = 0,1 → ≈ 0,86 %

Valable si les erreurs sont indépendantes et ε < 0,5. Difficulté : construire vite des modèles qui ne font pas les mêmes erreurs. VotingClassifier(estimators, voting="hard"|"soft", weights) ; VotingRegressor = moyenne.

CM4K plus proches voisins

  1. Distance à toutes les observations d'entraînement.
  2. Les K plus proches.
  3. Classe majoritaire (classification) ou moyenne (régression).
Vote pondéré : wᵢ = 1/dᵢ · Euclidienne √Σ(xⱼ − yⱼ)² · Manhattan Σ|xⱼ − yⱼ| · Minkowski (Σ|·|ᵖ)^(1/p)
  • K petit : flexible, sensible au bruit, variance élevée. K grand : lisse, biais élevé. Choisi en CV.
  • Normalisation indispensable (âge 20–80 contre salaire 20 000–100 000) : StandardScaler / MinMaxScaler.
  • Curse of dimensionality : en grande dimension, tout est loin, les distances perdent leur sens → PCA / LDA avant.
  • KNNImputer : impute avec les voisins (mieux que moyenne / médiane qui ignorent les autres observations).
  • Lazy : entraînement = mémoriser ; prédiction coûteuse.

KD-tree

Construction : médiane sur x₁, puis x₂ dans chaque moitié, en alternant → arbre équilibré. Recherche : descendre jusqu'à la feuille → candidat ; en remontant, si la distance de q au plan de coupe < meilleure distance, explorer l'autre côté, sinon élaguer.

Exemple du cours, q = (6,5 ; 5) : candidat (7,2) à 3,04, puis plus proche voisin (8,6) à √3,25 ≈ 1,80.

Coquille du CM : la distance à (8,6) est notée 1,08, c'est 1,80.

Tokenisation

  • Séparateurs : pas d'entraînement.
  • BPE (GPT) : fusionne la paire la plus fréquente ; à l'usage, applique les fusions dans l'ordre.
  • WordPiece (BERT) : fusionne la paire qui maximise P(ab)/(P(a)P(b)) ; à l'usage, plus longue sous-chaîne connue.

Embedding de phrase sans réseau

  • Bag of Words (CountVectorizer) : comptes. Réduire : minuscules, min_df, max_df, taille du vocabulaire, stop words, stemming (statistique, invente des mots, conseillé) ou lemmatisation (linguistique). Ordre perdu → n-grammes.
tfidf(t, d) = tf(t, d) × idf(t)
tf = occurrences de t dans d / nombre de mots de d · idf = log(N / nombre de documents contenant t)

Un mot présent dans tous les documents a idf = 0.

Embedding de mot sans réseau

  1. Matrice de co-occurrence (contexte : n mots avant / après). Corpus du cours : chat = [le 2, mange 1, aime 1].
  2. PPMI : corrige les mots très fréquents (« le »).
  3. SVD X = UΣVᵀ (U côté mots, Σ importance décroissante, Vᵀ côté contextes) → embedding U_kΣ_k.
PMI(w, c) = log P(w, c) / (P(w) P(c)) · PPMI = max(PMI, 0)
P_w = X.sum(axis=1, keepdims=True) / total   # (n, 1)
P_c = X.sum(axis=0, keepdims=True) / total   # (1, n)  ← axis=0 (le CM écrit axis=1)
mask = P_wc > 0                              # ← le CM écrit Pij
U, S, Vt = np.linalg.svd(PPMI); emb = U[:, :k] @ np.diag(S[:k])

Texte → moyenne des embeddings des mots, ou moyenne pondérée par TF-IDF.

Plan de réponse type à l'examen

  1. Nature du problème : régression / classification binaire / multi-classe, taille, type de features, déséquilibre.
  2. Métrique justifiée par le coût des erreurs.
  3. Prétraitement colonne par colonne, dans un Pipeline.
  4. Modèle(s) : une baseline simple + un modèle plus riche, avec la raison (interprétabilité, non-linéarité, vitesse).
  5. Hyper-paramètres à régler et leur effet sur biais / variance.
  6. Validation : CV (stratifiée), moyenne ± écart-type, test une seule fois.
  7. Lecture des résultats : over / under-fitting, choix final, limites.

!Pièges fréquents

  • score() = R² pour un régresseur, accuracy pour un classifieur.
  • C (logistique) est l'inverse de la régularisation ; alpha (Ridge / Lasso) est la régularisation.
  • Normaliser / imputer / SMOTE avant le split = fuite d'information.
  • Choisir les hyper-paramètres sur le test = estimation optimiste.
  • Accuracy élevée sur classes déséquilibrées ≠ bon modèle.
  • R² et MSE identiques ≠ même qualité de modèle (Anscombe).
  • Résidus studentisés tous < 3 ≠ relation forcément linéaire (jeu B : regarder la structure).
  • Prédire hors de la plage d'apprentissage (range prediction).
  • KNN sans normalisation ; KD-tree en très grande dimension.
  • Un arbre profond à 100 % en train : over-fitting, pas un bon modèle.
  • Scores d'erreur sklearn négatifs : neg_root_mean_squared_error.
  • Gradient boosting : η petit ⇒ plus d'arbres nécessaires ; trop d'itérations peut over-fitter.
