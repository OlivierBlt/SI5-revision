Entraînement sur les 5 CM (régression linéaire, régression logistique, arbres et ensembles, KNN, texte avant les transformers) et leurs labs, dans le style d'un examen à problèmes : diagnostic, calculs à la main avec formules données, choix de modèle justifié, pipeline scikit-learn.

données → split train/test → Pipeline(prétraitement → modèle) → GridSearchCV(cv, scoring) → meilleur modèle → score(test) une seule fois

Les barèmes sont indicatifs. Les corrigés signalent deux coquilles des CM (formule de SMOTE, distance 1,08 du KD-tree) et le code PPMI à corriger. Ta progression reste dans ce navigateur.
